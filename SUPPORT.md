# Suporte / Support

[Português (Brasil)](#português-brasil) · [English](#english)

## Português (Brasil)

Este é um projeto comunitário e **não oficial**; não há suporte comercial nem acordo de nível de serviço, e o projeto não fala em nome do Moodle HQ.

- **Documentação** de cada plugin: `https://moodle-fields-suite.github.io/<repositório>/` (por exemplo, `customfield_json`).
- **Dúvidas e problemas**: abra uma issue no repositório do plugin, com a versão do Moodle, do PHP e do plugin.
- **Vulnerabilidades**: não use issue pública; siga o `SECURITY.md` do repositório.

## English

This is a community, **unofficial** project; there is no commercial support or service-level agreement, and the project does not speak for Moodle HQ.

- **Documentation** of each plugin: `https://moodle-fields-suite.github.io/<repository>/` (for example, `customfield_json`).
- **Questions and problems**: open an issue in the plugin repository, with the Moodle, PHP and plugin versions.
- **Vulnerabilities**: do not use a public issue; follow the repository's `SECURITY.md`.
