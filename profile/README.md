# Boas-vindas à **Moodle Fields Suite**!

A **Moodle Fields Suite** reúne plugins de **campos** para o **Moodle** (não oficial): novos tipos de campo de perfil e de campo personalizado, e áreas de campos personalizados onde o Moodle não tem nenhuma, como categorias de curso, competências e emblemas.

Os plugins seguem o mesmo padrão de código, testes, documentação e publicação, e compartilham o plugin comum `local_fieldssuite`.

| Plugin | O que faz |
|---|---|
| [`profilefield_json`](https://github.com/moodle-fields-suite/profilefield_json) | Campo de perfil do usuário com um documento JSON e editor visual |
| [`customfield_json`](https://github.com/moodle-fields-suite/customfield_json) | Campo personalizado JSON para cursos, coortes, grupos e demais áreas |
| [`tool_categorycustomfields`](https://github.com/moodle-fields-suite/tool_categorycustomfields) | Campos personalizados para categorias de curso |

Confira mais detalhes no portal da organização:

> 🌐 [https://moodle-fields-suite.github.io](https://moodle-fields-suite.github.io)
